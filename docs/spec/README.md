# Feature specs and design records

These documents preserve requirements, acceptance criteria, and the reasoning behind feature work. They are useful when changing an existing feature or tracing a design decision. Some describe earlier behavior that later work superseded; check the current implementation, [user reference](../REFERENCE.md), and [architecture guide](../ARCHITECTURE.md) before treating a spec as the current product contract.
